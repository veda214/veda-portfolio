# Veda Gayatri Meesala — Portfolio

A responsive, single-page portfolio website built with plain HTML and CSS.

## Preview locally
Open `index.html` in a browser.

## Publish publicly with Vercel
1. Create a GitHub repository named `veda-portfolio`.
2. Upload `index.html` and this README to the repository root.
3. Sign in to Vercel using GitHub and choose **Add New → Project**.
4. Import `veda-portfolio`. No build command is required for this static HTML site.
5. Deploy. Vercel will provide a public `https://...vercel.app` URL that anyone can open.
